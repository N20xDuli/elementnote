ElementNote 隐私政策

最后更新：2026-11-11 · Last updated: 2026-11-11

1. 概述 / Overview

ElementNote 是一个完全在本机运行的浏览器扩展，用于在网页上选中元素、写批注、生成提示词。扩展不收集、不上传、不共享任何个人数据。

ElementNote is a fully local browser extension. It does not collect, transmit, or share personal data.

2. 扩展访问的内容 / What the extension reads

只有当你主动进入批注模式并选中元素后，扩展才在本机读取：

  • 当前页面的 URL、标题、视口尺寸、滚动位置
  • 被选中元素的标签、id、class、属性、文本、HTML 片段
  • 元素的位置、尺寸和计算样式
  • 页面公开挂载的 React/Vue/Angular 组件信息（只读）

这些内容仅保存在浏览器的 storage.local 中，按页面 URL 分片。它们不会发送给扩展作者或任何服务器。

3. 数据传输 / Transmission

扩展没有网络请求，没有账号系统、统计、遥测、广告或远程代码。

只有当你主动点击「复制提示词」或按 C，把内容粘贴到第三方 AI/聊天服务时，这些内容才会离开浏览器。此时适用该第三方服务的隐私政策。

4. 数据保留与删除 / Retention and deletion

  • 数据保存在本机，直到你删除批注、清空当前页，或卸载扩展。
  • 卸载扩展会清除其 storage.local 数据。
  • 你可以在扩展弹窗里逐条删除，或清空当前页面的全部批注。

5. 权限说明 / Permissions

  • storage：在本机保存批注与定位信息。
  • clipboardWrite：把你主动生成的提示词写入剪贴板。
  • scripting：在页面主世界只读读取组件栈（React fiber / Vue 实例等）。
  • <all_urls>：在你打开的任意页面上提供元素拾取器；只有你操作后才显示批注 UI。

扩展源码中没有 fetch、XHR、WebSocket、sendBeacon、远程脚本或 eval / new Function。

6. 儿童隐私 / Children

扩展不面向儿童，也不收集任何用户信息。

7. 变更 / Changes

如果未来版本增加任何数据收集或联网功能，会更新本政策并在扩展商店页面说明；在此之前，本政策描述的「纯本地」行为不变。

8. 联系 / Contact

如有隐私问题，请在 GitHub 提一个 issue：github.com/N20xDuli/elementnote/issues。

English summary

No network requests, no account, no telemetry, no remote code. Page content and annotations are stored only in the extension's local storage.local; data leaves the browser only when you explicitly copy a prompt and paste it into a third-party service. Uninstalling the extension clears its local data. Privacy questions: open an issue in the GitHub repository.
